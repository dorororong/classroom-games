# 교실 게임 (몸으로 말해요 · 이구동성 · 영어로 설명하기)

중2 교실 레크리에이션을 스케치북 없이 화면 하나(빔프로젝터 PC 또는 진행자 폰)로 진행하는 정적 웹앱. 서버·로그인·DB 없이 브라우저에서만 동작하고 GitHub Pages에 그대로 올린다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 진입점 |
| `style.css` | 테마 (게임별 색: 몸으로 말해요 빨강 · 이구동성 파랑 · 영어 보라, 다크 모드 지원) |
| `app.js` | 화면·게임 로직 (바닐라 JS) |
| `data/words.xlsx` | 원본 제시어 250개 (몸으로 말해요 110 = 속담 50 + 단어 60 · 이구동성 60 · 영어로 설명하기 80) |
| `data/words.json` | 웹앱이 읽는 제시어. `words.xlsx` 에서 변환한 것 |
| `tools/xlsx_to_json.py` | 엑셀 → JSON 변환 |
| `.nojekyll` | GitHub Pages가 Jekyll 처리를 건너뛰게 함 |

## 제시어 고치기

`data/words.xlsx` 를 고친 뒤 변환한다 (openpyxl 필요). 각 시트 5행이 머리글, 6행부터 데이터.

```bash
python tools/xlsx_to_json.py
```

출제 기록은 제시어 글자(`b:축구` 등)로 저장되므로 행 순서·번호는 자유롭게 바꿔도 된다. 제시어 글자를 고치면 그 제시어는 미사용으로 돌아간다. 같은 게임 안에 같은 제시어가 두 번 있거나, 이구동성이 네 글자가 아니면 변환이 멈춘다.

## 로컬 실행

`fetch` 로 JSON 을 읽어서 파일을 더블클릭하면 안 열린다.

```bash
python -m http.server 8766
```

## 게임 흐름

- **몸으로 말해요 · 영어로 설명하기** (스피드 라운드): (몸으로 말해요는 속담/단어 묶음을 먼저 골라 따로 출제) 카테고리·난이도·제한시간(30/60/90초/자유)·문제 수(5/10/15/20개/제한 없음, 정답+패스 합계)·차례 팀 선택 → 3·2·1 → 정답/패스 → 시간이 끝나거나 정한 문제 수를 채우면 결과(결과 칸을 누르면 정답↔패스 수정) → 다음 팀 시작. 영어는 진행자용 영어 예시를 숨겨 두었다가 필요할 때만 펼친다.
- **이구동성**: 진행자가 정답 확인 → 글자 카드 1~4를 하나씩 눌러 각 학생에게 자기 글자만 보여 줌 → ‘하나, 둘, 셋!’ 카운트다운(여러 번 가능) → 정답 공개 → 맞힌 팀(여러 팀 가능) 눌러 1점.
- 점수: 정답 1개 = 1점. 점수판에서 팀 추가·삭제(2~8팀)·이름 변경·점수 직접 가감.
- 출제 기록: 정답·공개한 제시어는 `사용`, 패스·건너뛴 제시어는 `보류`(엑셀의 진행 상태와 같은 이름). 기본은 미사용만 출제하고, 설정에서 보류도 다시 출제할 수 있다. 제시어 목록 화면에서 상태를 직접 바꿀 수 있다.
- 점수·출제 기록·설정은 `localStorage` 에 저장되어 새로고침해도 이어진다. 홈의 ‘새 게임’은 점수와 출제 기록을 지운다.

## 조작

| | 스피드 라운드 | 이구동성 |
|---|---|---|
| 정답 | → · Enter · PageDown | |
| 패스 | ← · PageUp | |
| 일시정지 | Space · 타이머 누르기 | |
| 제시어 가리기 | H · B · . (리모컨 화면 가림) | |
| 되돌리기 | Z · Backspace | |
| 하나·둘·셋 | | Space |
| 글자 카드 | | 1 ~ 4 |
| 정답 공개 / 다음 | | Enter · PageDown |
| 끝내기 | Esc | Esc |

진행 중에는 화면 꺼짐 방지(Wake Lock)를 켜고, 소리는 Web Audio 로 만들어 별도 파일이 없다.
